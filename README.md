# 芸茶 (YunCha) — 北欧极简风冷泡茶官网

项目概述
---------
芸茶（YunCha）是一个面向新加坡都市人群的冷泡茶 + 零食订阅品牌官网示例。网站风格为北欧极简主义，主打疗愈与草本配方，支持智能取货柜自取与至少提前 2 天预订。该项目使用纯原生 HTML/CSS/JavaScript 实现，不依赖任何前端框架或外部 API（除 Google Fonts）。

特色
- 北欧极简配色与排版：米白、自然绿、暖棕
- 响应式设计（Desktop / Tablet / Mobile）
- 产品数据以数组配置，便于季度更新
- 原生实现预订表单、日期验证、总价计算、模态确认
- 使用 localStorage 保存预订记录与草稿
- 代码中预留 AI 内容更新接口，便于未来扩展

文件结构
---------
- index.html — 页面结构（语义化标签、导航、Hero、产品、关于、预订表单、模态）
- style.css — 全局样式、变量、响应式媒体查询、动画过渡
- script.js — 产品数据、产品渲染、表单验证、价格计算、localStorage、模态逻辑、AI 占位接口
- README.md — 项目说明

快速开始
---------
1. 克隆或下载文件到本地目录。
2. 在浏览器中打开 `index.html` 即可预览（无需服务器）。
   - 推荐使用 Chrome / Edge / Safari 等现代浏览器以获得最佳体验。

开发与测试
-----------
- 编辑产品：在 `script.js` 的 `products` 数组中添加、修改或删除对象即可更新前端展示（季度更新）。
- 表单验证：取货日期自动设置为今日 + 2 天（作为最小值），提交会做前端校验。
- 本地保存：提交后预订会保存到 localStorage（键名：`yuncha_bookings`）。草稿保存键名：`yuncha_draft`。
- 模态确认：提交后会弹出确认模态并显示预订摘要。

部署指南
---------
静态站点，可部署至任何静态主机（例如 GitHub Pages、Netlify、Vercel、S3 + CloudFront 等）：
1. 将以下文件放到部署目录：
   - index.html
   - style.css
   - script.js
2. 确保 `index.html` 中的相对路径引用（style.css / script.js）保持正确。
3. 上传并发布即可。

可选：如果想在生产环境连接后端：
- 将 `booking` 的提交逻辑替换为 fetch POST 到后端 API（例如 `/api/bookings`）。
- 后端应负责存储、库存检查、短信或邮件确认等。

未来扩展建议
--------------
- 后端 API 集成：订单持久化、库存、取货柜管理、通知（SMS/WhatsApp）。
- 支付集成：加入线上支付（Stripe / PayPal / 本地支付）以完成预付与订阅。
- 用户账户：支持订阅管理、历史订单查看、自动续订。
- 仓储与取货柜接口：与智能取货柜系统对接（取货码生成、上架通知）。
- AI 驱动的菜单更新：使用预留的 `fetchAIGeneratedContentForQuarter()` 接口与 AI 服务整合，自动生成和推荐季度新品及描述。
- 国际化（i18n）：添加英文等多语言支持以覆盖更广用户群。
